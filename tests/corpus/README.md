# Characterization corpus

These compact JSON assets were copied byte-for-byte from the common example
resources present in both supplied rlottie archives. Their purpose is to
characterize existing behavior before internal extraction or renaming.

Coverage:

- `StickAndBall.json`: basic transforms and shapes;
- `ModernPictogramsForLottie_LoudMute.json`: UI icon animation;
- `1667-firework.json`: multi-shape animation;
- `mask.json`: mask path;
- `polystar_line_clockwise_trim.json`: trim path and polystar;
- `gradient_animated_background.json`: animated gradient;
- `dynamic_path_test.json`: animated path data;
- `matte_two_item_with_lowerlayer.json`: matte composition.

The corpus is reference material, not a claim that every feature belongs in the
first AveMotion production profile.
