# Deterministic TGS compatibility corpus

This directory is a transport and validation corpus for AveMotion.  Every
`.tgs` file is generated byte-for-byte deterministically from an already versioned JSON
fixture or characterization asset by `scripts/generate_tgs_compatibility_corpus.py`.

The generator uses a canonical gzip header and stored DEFLATE blocks so the
result does not depend on the host zlib version. Dynamic-Huffman coverage remains
in the Part 22 decoder fixtures.

The corpus is deliberately **not presented as a downloaded real-world Telegram
sticker pack**.  It provides reproducible coverage for:

- JSON/TGS byte identity after bounded decompression;
- canonical-model identity between the two transports;
- feature inventory and validation profiles;
- native Direct2D, native-subset and preserved reference-fallback cases;
- one strictly authored 512x512, 60 FPS, loop-intended Telegram-profile asset.

Regenerate:

```bash
python3 scripts/generate_tgs_compatibility_corpus.py --root .
```

Verify without modifying files:

```bash
python3 scripts/generate_tgs_compatibility_corpus.py --root . --check
```

The source JSON path, generated TGS path, sizes and SHA-256 are pinned in
`manifest.tsv`; per-file payload hashes are also listed in
`tgs/SHA256SUMS.txt`.

A later private real-sticker corpus should be added as a separate, rights-
reviewed input set rather than mixed silently into this deterministic fixture
corpus.
